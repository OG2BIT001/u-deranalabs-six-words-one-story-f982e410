Six Words, One Story: a program that writes one complete story in exactly six words — *"He practised saying goodbye. Never left."* — a man rehearses leaving, over and over, and never does. Drafted from a six-candidate shortlist in-session and revised in the same session; the program validates the gate itself (exactly six words, 1–60 characters, one line ending on a full stop) before writing `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
